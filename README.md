# BucketList

A personal, local-first macOS bucket-list app built with SwiftUI and SwiftData.

## Features

- DONE, NEAR FUTURE, TODO, and RECAP sections
- Editable and reorderable activities with emoji
- Completion memories with a date, full thoughts, photos, and videos
- App-managed local media storage
- A full-content vertical RECAP feed with native video playback
- A bundled 25-item starter list

## Requirements

- macOS 14 or newer
- Xcode 16 or newer

Open `BucketList.xcodeproj`, select the `BucketList` scheme, and run the macOS target.
